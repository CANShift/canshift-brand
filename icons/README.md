# CANShift — repository icons

Five marks, one per repo under [github.com/CANShift](https://github.com/CANShift).
Built on the CS monogram grid: 116 × 100 frame, 13-unit stroke, 11° shear, exactly one red element each.

| Repo | The mark says |
| --- | --- |
| `canshift-firmware` | a chip from above — the red leg is the CAN line |
| `canshift-tuner` | three rails and three handles, the middle one being dragged |
| `canshift-mobile` | a handset with two red signal bars — BLE, iOS and Android |
| `canshift-docs` | four rules of falling length, the red one is the line you came to read |
| `canshift-core` | two brackets closing on one red bar — frames in, a decoded signal out |

## Files per repo

| File | Use |
| --- | --- |
| `<name>.svg` | ink #201E1D on light grounds, accent #EC3013 |
| `<name>-dark.svg` | #F3F2F2 on dark grounds, accent #FF4747 |
| `<name>-currentcolor.svg` | ink follows the surrounding text colour |
| `<name>-small.svg` | 16–24 px variant: no shear, 15-unit stroke |
| `<name>-small-dark.svg` | same, on dark |
| `<name>-avatar-460.svg` | 460 × 460 repo avatar on #151313 — what GitHub shows |

## Rules

- One accent element per mark. Never two, never a red outline.
- On dark grounds the accent becomes #FF4747 — the same red as the dash.
- Below 24 px use the `-small` variant: the shear closes up and the stroke thickens to 15 u.
- Do not rotate, recolour the ink to the accent, or add a container shape. The avatar square is the only plate.
- A sixth repo gets the same treatment: one red element, and it must name what the repo does.
